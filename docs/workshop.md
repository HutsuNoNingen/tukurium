# 保存したアイテムをワークショップに公開する

マイライブラリの保存版を公開し、ほかのHNの利用者が保存・編集・共有・再公開できる。HNだけでログインする仕様は継続する。同じHNを使う人は同じライブラリと操作権限を持つ。

## 公開と取得

1. ワールドでアイテムを選び、「ホーム / ライブラリ」を開く。
2. 「マイライブラリ」の「選択中のアイテムを保存」を押す。見た目・設定・ロジックを一つの保存版として記録する。
3. 保存したカードの「詳細を見る」から「ワークショップに公開…」を選ぶ。
4. 作品名と説明を入力し、「公開する」を押す。
5. ほかの利用者は「ワークショップ」で作品を探し、「ライブラリに保存」を押す。取得した作品は自分のライブラリからワールドに配置できる。

## ライセンス制限は保留する

2026-10-24時点では、ワールド内の操作とライブラリの保存・取得・共有・再公開を、所有者や利用条件の値で制限しない。古い保存版や公開作品の条件も操作の拒否には使わない。公開・共有の画面には利用条件の選択欄を出さない。

作者・派生元・保存日時は記録する。正式なライセンスの導入順序と作品の境界は、[今後の計画](item-boundaries-and-rights.md)にまとめる。

## 公開後の扱い

公開対象は変更されない保存版である。公開後にワールドで制作を続けても、配布中の内容は変わらない。変更した作品を出すときは新しく保存し、その版を公開する。

同じ保存版を同じHNから重複して公開できない。別の利用者は同じ保存版を自分の公開作品として再公開できる。元の作者情報は維持する。

「公開を停止」はワークショップの一覧と、その公開情報からの追加を止める。保存版・取得済みのライブラリ・配置物は残る。サインイン済みなら、保存版IDや素材ハッシュを指定した取得は引き続きできる。個人のライブラリの名前変更・削除と、公開情報の停止は本人が行う。

## 画面の方針

参考にしたのは [Tonarium Prototype](https://github.com/katteni-kaihatu/tonarium-prototype) のホーム画面、サイドバー、セッションカードである。ローカルの `client/src/home/`、`client/src/style.css` と保存済みの画面画像を確認した。

明るい紙色のパネル、青い選択色、左のナビゲーションを取り入れた。`frontend-design` と `baseline-ui` の指針を、既存のGodotコントロールへ適用している。作品一覧と詳細を分け、カードに操作ボタンを詰め込まない。公開停止とライブラリからの削除には確認ダイアログを設ける。

保存時には、選択した描画ノードだけを別の描画領域で撮影する。新しいサムネイルは240×150以下のPNGで、ワールド全体やホーム画面を写し込まない。サムネイルのない既存作品には種類ごとの図形を表示する。

## APIと保存

既存の `POST /v1/rpc` に次の操作を追加した。ログインで発行されたセッションキーが必要である。

| action | 主な入力 | 内容 |
|---|---|---|
| `workshop` | `query`, `offset`, `mine` | 公開中の作品を新しい順に12件ずつ取得 |
| `workshop_detail` | `publication_id` | 公開情報とライブラリへの追加済み状態を取得 |
| `publish_item` | `version_id`, `title`, `description` | 保存版を公開。ライセンスの指定は不要 |
| `unpublish_item` | `publication_id` | 公開者が新しい取得を停止 |
| `acquire_item` | `publication_id` | 自分のライブラリへ追加し、取得履歴を記録 |

公開・停止・取得は `request_id` による再試行に対応する。同じHNによる同じ公開作品の再取得で、取得数やライブラリ登録が重複しない。素材取得にはサインインが必要で、ハッシュ・形式・容量の検証は維持する。

データは既存のSQLiteに `publications` と `acquisitions` として保存する。既存の保存版・ライブラリは維持する。1つのHNから同時に公開できる作品は100件、説明は2000文字まで。公開ストアの決済、評価・コメント、通報・審査は今回の実装範囲に含めない。

## 検証

```powershell
. ./scripts/env.ps1
cargo test --workspace --locked
cargo clippy --workspace --all-targets -- -D warnings
node tests/managed-integration.mjs --rendered
```

他人の配置物の保存、取得したモデルの派生保存・共有・再公開、作者の維持、検索・ページ分割、再取得、公開停止後の保存版の維持、再起動後の永続化を確認する。Godotでは保存・公開ダイアログ・別HNでの取得・公開停止を操作し、画面画像を生成する。
