Kokoverse Workshop - Windows x64 prototype

【起動】
ZIPを右クリックして「すべて展開」してください。ZIPの中から直接起動しないでください。
Rust / Go / Godot のインストールや、管理者としての実行は不要です。
Windows 10/11（64bit）と、OpenGL 3.3対応のグラフィックス環境が必要です。

1. Start.bat をダブルクリックします。
2. 表示するユーザー名を入力して「Join」を押します。
3. 最初の人がホストになり、後から来た人は同じワールドへ自動で参加します。
4. Godotの画面が開きます。動画用ツールは初回だけ背後で約110 MBダウンロードします。
5. 終了時は Stop.bat を使います。画面を閉じただけではEngineは終了しません。

同じPCで2画面を開く場合は、フォルダーをコピーしてそれぞれのStart.batを起動します。
ローカル通信用ポートは自動で空きを選びます。コピー先では参加者IDも作り直します。

ホストは1人です。ホストが切断した場合、既存の参加者は編集を止めて復帰を待ちます。
ホストを終了するとワールドの変更は失われます。保存UIと自動ホスト交代は未実装です。

【固定接続先】
接続先: wss://45.77.130.146/ws
ルームID: kokoverse/workshop
ホストpeer: host
参加者peer: 接続時に自動で生成するID

同じZIPから起動した人は、この同じルームに参加します。
接続情報の同梱版にはrelay-access.jsonが入り、入力なしで接続します。
同梱されていない場合は、主催者から受け取った接続用パスワードを入力します。
入力した資格情報は .run/relay-login.xml にWindowsアカウントで暗号化して保存します。
入力し直す場合は、Stop.batのあとでこのファイルを削除してください。

【操作】
WASD: 移動 / Space: ジャンプ / V: 視点切替 / I: インスペクタ表示切替
物体をクリック: 選択 / ギズモをドラッグ: 移動 / インスペクタ: 値を自動同期
FPSで右クリック長押し: 物体を保持 / ホイール: 距離 / E+マウス: 回転
Shift+ホイール: 拡縮 / 左クリック: 傾きを起こす / Esc: 操作を解除
画像・GLB・FBX・MP4などをD&D: ワールドへ追加
モデルと動画は1ファイル100 MiBまで。動画は最大720p/30fpsへ変換します。
動画選択後: Play/Pause・Restart・シーク・Loopを共有操作できます。
PEOPLEの「Avatar texture…」: お絵描きアバター用のPNG/JPEG/WebPを選んで見た目を変更
PEOPLEの「Reset」: 標準のアバターテクスチャに戻す
テクスチャは相手や途中参加者にも共有され、自分の次回起動時にも引き継がれます。

【このZIPに入っているもの】
アプリ本体と実行環境、お絵描きアバター、起動スクリプト、ソース、ライセンス通知。
アバターの出典は client-godot/assets/oekaki/README.md に記載しています。
開発中のワールド、私用の画像・動画・モデルは含めていません。
FFmpegの実行ファイルは同梱せず、初回に配布元から取得します。
後から取得する場合は Install-Video-Tools.bat を実行してください。

【確認・ログ】
.run/engine.log / .run/engine-error.log: Rust Engine
.run/adapter.log / .run/adapter-error.log: サーバー接続
.run/startup.log: 起動処理の進行状況
.run/media-setup.log / .run/media-setup-error.log: 動画ツールの準備状況
.run/assets/: 取得したモデル・動画
.run/media/: 動画の表示用キャッシュ
接続できない場合は、ユーザー名・パスワードとHTTPS通信の制限を確認してください。
認証情報を同梱したこの版では、接続パスワードの入力は不要です。
動画ツールの準備中でも、移動・編集・画像やモデルの取り込みは使えます。
別のPC・ネットワーク間での品質は接続環境に依存します。

この試作ではルーム参加者全員がワールドを編集できます。
外部素材を追加する場合は、共有・配布の許可がある素材を使ってください。
