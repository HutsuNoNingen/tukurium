Kokoverse Workshop - Windows x64 prototype

【起動】
ZIPを右クリックして「すべて展開」してください。ZIPの中から直接起動しないでください。
Rust / Go / Godot のインストールや、管理者としての実行は不要です。
Windows 10/11（64bit）と、OpenGL 3.3対応のグラフィックス環境が必要です。

1. Start.bat をダブルクリックします。
2. Godot画面の HN にハンドルネームを入力し、Startを押します。
3. 同じHNなら別のPCでも同じライブラリを使えます。パスワードは不要です。
4. 「作成」でセッションを作るか、一覧から「参加」を押します。
5. Engineのコンソールにログが表示されます。コンソールの×でワールドを保存して終了します。
   各ログ窓の×で、そのインスタンスだけを保存して終了できます。「退出」はセッションを抜けてホームに戻ります。
   Start.batは押すたびに別のインスタンスを起動します。プロファイルはdefault、instance-2、instance-3…と自動で分かれます。
   終了済みのプロファイルは、保存データを残して再利用します。Stop.batはdefaultだけを終了します。

「ホーム / ライブラリ」からアイテムを保存・配置・共有できます。
マイライブラリの「詳細を見る」→「ワークショップに公開…」で作品名と説明を入力します。
ワークショップで作品を選び、「ライブラリに保存」すると自分の棚へ追加されます。
他の人の作品も保存・編集・共有・再公開できます。ライセンスの制限は現在設けていません。
公開を停止しても、保存済みの作品は残ります。
ホストが退出するとセッションは終了します。ホストの自動交代は未実装です。
以前のワールドを再開するときは 「保存ワールドから…」 から保存JSONを選びます。
動画の取り込みを使う場合は、Install-Video-Tools.bat で変換ツールを導入してください。

同じPCで別ユーザーとして試す場合も、Start.batをもう一度押して別のHNを入力します。
同じプロファイルの画面を開き直したい場合は、PowerShellで次を実行します。
./scripts/start-online.ps1 -Profile guest
終了は ./scripts/stop-online.ps1 -Profile guest です。

【接続先と保存先】
管理API: https://45.77.130.146/api
リアルタイム同期: wss://45.77.130.146/ws
接続先は connection.json で指定します。

.run/online/<profile>/worlds/: ホストのワールド
.run/online/<profile>/assets/: モデル・動画などのキャッシュ
本人情報: WindowsのLOCALAPPDATA内 Kokoverse/servers/ 以下（暗号化）
接続用パスワード: 不要。以前の保存済み資格情報も使いません。

サーバーには個人ライブラリの保存版と素材が残ります。
同じHNを入力すれば、同じ利用者として保存済みライブラリを開けます。
前後の空白は除き、大文字小文字は区別します。同じHNを知る人は同じデータを操作できます。
ワールドを移すときはworlds内のJSONとassetsの内容を一緒に移してください。

【操作】
WASD: 移動 / Space: ジャンプ / F5: 視点切替（初期はFPS）/ I: 2Dインスペクタ
起動時はカーソルを表示。ワールドをクリックするとFPS操作を開始します。
ミドルクリック: リングメニューから2D・3Dインスペクタ、新規作成、読み込み
新規作成: 3DパネルでBox・Sphere・Capsule・Cylinder・Cone・Torus・Grid・Quadを選択
作成パネルはインスペクタと同じ共有3Dパネルです。開いたまま移動・ジャンプでき、右クリックで保持・回転・拡縮できます。
作成に成功するとパネルは全員の画面から閉じ、作成した物体だけがワールドに残ります。
Esc: リング／ダッシュを閉じてカーソルを表示。3Dパネルは残ります。左上の☰でダッシュメニューを開く。
Ctrl+I: 選択した物体の共有インスペクタをワールド内に追加（最大16枚）
Ctrl+Shift+I: ローカルの2Dインスペクタだけを開く（3Dパネルは追加しません）
2D窓の対象選択・階層表示・タブ・スクロールはローカル。値やコードの編集は共有します。
パネルの選択欄: 表示対象を変更 / +: 複製 / ×: 閉じる
共有パネルもFPSの右クリック保持・E回転・Shift+ホイール拡縮で配置できます。
入力中の文字・スクロール・編集者も共有し、他の人が編集中の欄は編集不可になります。
文字入力中のSpaceはジャンプしません。パネルの配置と対象はワールドに保存されます。
物体をクリック: 選択 / ギズモをドラッグ: 移動 / インスペクタ: 値を自動同期
FPSで右クリック長押し: 物体を保持 / ホイール: 距離 / E+マウス: 回転
Shift+ホイール: 拡縮 / 左クリック: 傾きを起こす / Esc: 操作を解除
画像・GLB・FBX・MP4などをD&D: ワールドへ追加
モデルと動画は1ファイル100 MiBまで。動画は最大720p/30fpsへ変換します。
動画選択後: Play/Pause・Restart・シーク・Loopを共有操作できます。
Esc → ☰ → ユーザー設定 →「テクスチャを選択」: お絵描きアバター用のPNG/JPEG/WebPを選んで見た目を変更
Esc → ☰ → ユーザー設定 →「リセット」: 標準のアバターテクスチャに戻す
テクスチャは相手や途中参加者にも共有され、自分の次回起動時にも引き継がれます。

【自分で動作を作る】
物体を選び、Inspectorの「Script Systems…」を開きます。
Rotator（回転）またはClickColor（クリックで色変更）を選び、「+ Add component」で追加します。
コードを書き換えて「Apply / restart」で反映します。公開パラメータの値は自動同期します。
「Run on host」で停止・再開、「Test click」または物体の左クリックでクリック処理を実行します。
コードと明示的な状態はワールドと一緒に保存され、Duplicateでも複製できます。
構文エラー時は前のコードを保持し、実行エラーでは該当スクリプトを停止します。
現在は1つの物体内を操作できます。4部品/物体、32部品/ワールド、ソース8 KiBまで。
ホストと参加者は、このScript Systemsに対応した同じ更新版を使ってください。

【確認・ログ】
.run/engine.log / .run/engine-error.log: Rust Engine
.run/adapter.log / .run/adapter-error.log: サーバー接続
.run/startup.log: 起動処理の進行状況
.run/media-setup.log / .run/media-setup-error.log: 動画ツールの準備状況
.run/assets/: 取得したモデル・動画
.run/media/: 動画の表示用キャッシュ
接続できない場合は、サーバーの稼働状況とHTTPS通信の制限を確認してください。
HNの変更は別ユーザーへの切り替えです。以前のHNに戻れば以前のライブラリを使えます。
動画ツールの準備中でも、移動・編集・画像やモデルの取り込みは使えます。
別のPC・ネットワーク間での品質は接続環境に依存します。

ワールドの共同操作とライブラリの保存・改変・再配布を、所有者や利用条件で制限しません。
外部素材を追加する場合は、共有・配布の許可がある素材を使ってください。
